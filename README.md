# 🚀 Featured Projects

## 🤖 AI SQL Data Analyst Agent

**Python • LangChain • Groq • MySQL • Streamlit**

An AI-powered SQL Data Analyst Agent that allows users to ask questions about databases using **natural language** and receive query results without manually writing SQL.

### What I built

* 🧠 Natural-language → SQL generation
* 🗄️ Dynamic database schema loading
* 🔄 Automatic SQL error correction
* 💬 Conversational memory
* 📂 Multi-database project selection
* 🐬 MySQL integration
* 🖥️ Streamlit interface

The agent uses the **actual database schema** to generate queries rather than relying on assumptions, and can send failed SQL queries back to the LLM with error and schema context for correction.

**→ [View Project](https://github.com/Yadnyavalk/AI-SQL-Data-Analyst-Agent)**
